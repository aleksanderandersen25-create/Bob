# Quick Start Guide

## How to Use the Fiber Optic Installation Documentation App

### Starting the Application

1. **Open the app**: Simply open `index.html` in any modern web browser
   - Double-click `index.html` on your computer, OR
   - Serve it from a web server (e.g., `python3 -m http.server`)

### Documenting a New Installation

1. Click the **"New Installation"** tab
2. Fill in the required fields (marked with *):
   - Project Name
   - Location
   - Installation Date
   - Cable Type (choose from dropdown)
   - Fiber Count
   - Cable Length
3. Fill in optional fields for complete documentation:
   - Client name
   - Manufacturer
   - Splice information
   - Testing results
   - Technician name
   - Installation notes
   - Issues encountered
4. **Add Installation Photos** (Optional):
   - Click **"Choose Files"** in the Installation Photos section
   - Select one or more images (JPG, PNG, etc.)
   - Edit the name of each photo for easy identification
   - Remove unwanted photos before saving
5. Click **"Save Installation"**

### Viewing Projects

1. Click the **"Projects"** tab
2. Use the search bar to find specific projects
3. Click on any project card to view detailed information
4. Projects with photos show the photo count
5. Use the **Delete** button to remove a project

### Generating Reports

1. Click the **"Reports"** tab
2. Use the dropdown to filter by test status (All/Passed/Failed/Pending)
3. Review detailed reports with all installation data
4. **View Photos**: See all installation photos in the photo gallery
5. **Download Photos**: Click the download button on any photo to save it
6. **Send via Email**: Click **"Send via Email"** to open your email client with a pre-filled report
   - Email includes all installation details
   - Download and attach photos manually to the email
7. Use **"Export All Data (JSON)"** to backup your data
8. Use **"Clear All Data"** to delete all records (with confirmation)

### Data Management

- **Automatic Save**: All data is saved automatically in your browser
- **Persistent**: Data persists between sessions
- **Export**: Use the export button to create a JSON backup file
- **Import**: Currently manual - future feature planned

### Browser Compatibility

✅ Chrome/Edge  
✅ Firefox  
✅ Safari  
✅ Opera  

### Tips

- Regularly export your data for backup
- Fill in all testing results for complete documentation
- Use descriptive project names for easy searching
- Include detailed notes about cable routes and installation specifics
- **Add photos** of key installation points (cable routes, splice trays, patch panels, etc.)
- **Name photos descriptively** (e.g., "Main Distribution Frame", "Floor 3 Splice Tray")
- Download photos from reports before emailing them to clients
